# Ship a prebuilt reference database with Blizzard-derived data

We publish a prebuilt SQLite database containing Client Data (DBC contents), the FrameXML source and other Blizzard-derived material. We accept the licensing risk because community projects commonly do the same, and we act on takedown requests. The alternative, building the database locally from each user's own client, would make install depend on a client path and a local extraction step. Once a release is published it cannot be fully unpublished, so this choice is effectively permanent for every released version. Attribution and licence obligations of each source still apply. See [What obligations do the candidate sources impose on a public npm package?](https://github.com/denisdasilvarocha/wotlk-mcp/issues/6).
