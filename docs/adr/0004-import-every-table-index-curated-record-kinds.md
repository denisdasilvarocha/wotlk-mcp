# Import every source table, index a curated set of record kinds

The pipeline imports Game Data generically: every DBC with a 12340 WoWDBDefs layout and every AzerothCore world table except locale, emulator scripting/AI and server bookkeeping tables, with every field under its upstream name. Only a curated list of record kinds is indexed for search, get and related; everything else is reachable through raw SQL. We rejected a hand-picked table and field allowlist: it needs ongoing curation and makes anything left out unreachable, while sparse rendering already keeps wide records cheap. Because raw SQL is exposed, the imported table and column names are public interface, so narrowing the import later is a breaking change. This is why the database also holds tables that look irrelevant, such as animation DBCs.
