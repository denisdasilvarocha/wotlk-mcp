# Security Policy

## Supported versions

Security fixes go to the latest release only.

## Reporting a vulnerability

Do not open a public issue. Report it privately through [GitHub private vulnerability reporting](https://github.com/denisdasilvarocha/wotlk-mcp/security/advisories/new).

Include the affected version, steps to reproduce, and the impact you expect. We aim to acknowledge reports within 7 days and will keep you updated until a fix is released. We credit reporters in the advisory unless you ask us not to.
